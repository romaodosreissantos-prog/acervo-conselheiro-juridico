# Acervo Conselheiro Juridico - Link Card

Acervo doutrinario em texto completo, convertido para Markdown e dividido em partes por obra.

Uso: o Conselheiro Juridico busca o indice da area/obra relevante e depois busca apenas a(s) parte(s) necessaria(s), sem carregar o livro inteiro.
